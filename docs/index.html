Questions

Short answers.

Which APK should I download?

Almost every modern phone needs arm64-v8a. If it does not install, try armeabi-v7a. The x86_64 file is only for emulators.

Where are my files saved?

In Download/0XDL, inside a folder named after the platform (YouTube, Pinterest, CapCut…). You can turn the per-platform folders off in Settings.

Why does it ask for “all files access”?

To save files straight into your public Download folder and to bring your list back after a reinstall. The app never reads anything else.

Does it need an account or send my data anywhere?

No. There is no account, no server and no analytics. The only network traffic is to the sites you download from, to GitHub for updates, and for the downloader engine updates.

A site stopped working. What now?

The downloader engine updates itself automatically. Open the app and try again after a moment. If it keeps failing, open an issue on GitHub.

Is it legal?

Download only what you have the right to download, and follow each site's terms. You are responsible for how you use the app.
